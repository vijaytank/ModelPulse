# Security Policy

## Supported Versions

We actively monitor and support the following versions of ModelPulse:

| Version | Supported | Notes |
| :--- | :--- | :--- |
| 1.0.x |  Yes | Active MVP stability and security patches. |
| < 1.0.0 | ❌ No | Pre-release spikes; please upgrade to 1.0.0. |

---

## Reporting a Vulnerability

**Do NOT report security vulnerabilities via public GitHub issues.** 

If you discover a security vulnerability in ModelPulse, please report it privately:
1. Include a detailed description of the vulnerability, steps to reproduce, and any proof-of-concept (PoC) code or environment configurations.

### Our Commitment & SLA

*   **Acknowledgment**: We will acknowledge receipt of your vulnerability report within **48 hours**.
*   **Triage**: We will investigate and verify the vulnerability within **5 business days**.
*   **Resolution & Disclosure**: We will work with you to coordinate a security patch and release before public disclosure, targeting a resolution within **30 days**.
